## 1. Краткое описание реализуемых методов

### 1.1. Формула центральных прямоугольников
На отрезке $[a,b]$ с шагом $h=(b-a)/n$:
$$I \approx h\sum_{i=0}^{n-1} f\!\left(a+\left(i+\tfrac12\right)h\right).$$
Погрешность метода:
$$|R|\le \frac{(b-a)h^2}{24}\,M_2,\qquad M_2=\max_{x\in[a,b]}|f''(x)|.$$

### 1.2. Метод трапеций
$$I \approx \frac{h}{2}\left(f(a)+2\sum_{i=1}^{n-1}f(a+ih)+f(b)\right).$$
Погрешность:
$$|R|\le \frac{(b-a)h^2}{12}\,M_2.$$

### 1.3. Метод Симпсона
$$I \approx \frac{h}{3}\left(f(a)+4\sum_{i=1,3,\dots}^{n-1}f(x_i)+2\sum_{i=2,4,\dots}^{n-2}f(x_i)+f(b)\right),$$
где $n$ — чётное. Погрешность имеет порядок $O(h^4)$.

### 1.4. Правило Рунге (автовыбор шага)
Для трапеции:
$$\tilde I_h \approx I,\qquad \frac{|I_h-I_{h/2}|}{3}\le \varepsilon.$$
Для Симпсона:
$$\frac{|S_h-S_{h/2}|}{15}\le \varepsilon.$$
Если условие не выполнено, шаг уменьшается вдвое.

## 3. Поиск точного значения определённого интеграла по формуле Ньютона–Лейбница

Находим первообразную:
$$\int x e^x\,dx = x e^x - e^x = e^x(x-1).$$
Тогда
$$I=\int_0^1 x e^x\,dx = \Big[e^x(x-1)\Big]_0^1 = 0-(-1)=1.$$

**Точное значение (4 знака после запятой):** $I^*=1.0000$.

## 4. Расчёт выбора шага для метода центральных прямоугольников и трапеции

Для $f(x)=x e^x$:
$$f''(x)=e^x(2+x).$$
На $[0,1]$ максимум достигается в точке $x=1$:
$$M_2=\max_{[0,1]}|f''(x)|=3e\approx 8.1548.$$

### 4.1. Центральные прямоугольники
Из
$$|R|\le \frac{h^2}{24}M_2\le \varepsilon$$
получаем
$$h\le \sqrt{\frac{24\varepsilon}{M_2}} \approx 0.0542.$$
Берём $n=\lceil 1/h\rceil=19$, тогда $h=1/19\approx 0.0526$.

### 4.2. Трапеции
Из
$$|R|\le \frac{h^2}{12}M_2\le \varepsilon$$
получаем
$$h\le \sqrt{\frac{12\varepsilon}{M_2}} \approx 0.0383.$$
Берём $n=27$, тогда $h=1/27\approx 0.0370$.

## 5. Текст программы

Файлы:
- `integration_methods.py` — прямоугольники, трапеции, Симпсон, правило Рунге
- `p1_integration.py` — расчёт для варианта 7

Ключевой фрагмент (автовыбор шага по Рунге):
```python
def integrate_with_runge(method, f, a, b, *, eps, start_n=2):
    compute = trapezoid if method == "trapezoid" else simpson
    denom = 3.0 if method == "trapezoid" else 15.0
    n = max(2, start_n)
    i_coarse = compute(f, a, b, n)
    while True:
        i_fine = compute(f, a, b, 2 * n)
        if abs(i_coarse - i_fine) / denom <= eps:
            return i_fine, 2 * n
        i_coarse, n = i_fine, 2 * n
```
