## 2. Краткое описание реализуемых методов

### 2.1. Гаусс (с выбором главного элемента по столбцу)
Прямой ход приводит $A$ к верхнетреугольному виду (зануляем элементы под диагональю), при этом используем **частичный выбор ведущего элемента** (pivot) в столбце для устойчивости. Затем обратный ход (подстановка) даёт решение.

### 2.2. Хаусхолдер (QR)
Отражениями Хаусхолдера преобразуем $A$ к верхнетреугольной $R$ так, что $Q^TA=R$, и одновременно применяем те же преобразования к $b$: получаем $Q^Tb$. Затем решаем $Rx=Q^Tb$ обратной подстановкой.

### 2.3. Прогонка (метод Томаса) для трёхдиагональной матрицы
Для трёхдиагональной матрицы строится прямой ход по коэффициентам $\alpha_i,\beta_i$, затем обратный ход для $x_i$.

### 2.4. Невязка, нормы, оценки ошибки
Невязка: $r=b-Ax_{\text{hat}}$. Используются:
- $\|v\|_1=\sum|v_i|$,
- $\|v\|_\infty=\max|v_i|$.

Если известно точное $x$, фактическая ошибка: $e=x_{\text{hat}}-x$.

Предельная оценка относительной ошибки через число обусловленности:
$$\frac{\|x-x_{\text{hat}}\|}{\|x\|}\le \kappa(A)\cdot \frac{\|r\|}{\|b\|},\qquad \kappa(A)=\|A\|\cdot\|A^{-1}\|.$$

### 3.1. Гаусс (идея pivot + исключение)
```python
pivot = k + np.argmax(np.abs(A[k:, k]))
A[[k, pivot]] = A[[pivot, k]]
B[[k, pivot]] = B[[pivot, k]]
factor = A[k + 1 :, k] / A[k, k]
A[k + 1 :, k:] -= factor[:, None] * A[k, k:]
B[k + 1 :, :] -= factor[:, None] * B[k, :]
```

### 3.2. Хаусхолдер (применение отражения)
```python
R[k:, k:] -= beta * np.outer(v, v @ R[k:, k:])
Y[k:, :] -= beta * np.outer(v, v @ Y[k:, :])
```

### 3.3. Прогонка (прямой/обратный ход)
```python
alpha[i] = -c[i] / den
beta[i] = (d[i] - a[i] * beta[i - 1]) / den
# ...
x[i] = alpha[i] * x[i + 1] + beta[i]
```

## 5. Анализ полученных результатов (влияние числа обусловленности)

Числа обусловленности (оценка порядка):
- для системы 1: $\kappa_1(A_g)\approx 3.52\cdot 10^0$, $\kappa_\infty(A_g)\approx 3.38\cdot 10^0$ (хорошая обусловленность);
- для системы 2: $\kappa_1(A_b)\approx 7.23\cdot 10^7$, $\kappa_\infty(A_b)\approx 1.88\cdot 10^8$ (плохая обусловленность).

Выводы:
- у **хорошо обусловленной** системы невязки порядка $10^{-13}$ дают фактические ошибки порядка $10^{-16}$ (ошибка почти не усиливается);
- у **плохо обусловленной** системы невязка тоже мала ($\sim 10^{-13}$), но ошибка решения заметно больше ($10^{-9}\dots 10^{-8}$): обусловленность усиливает влияние округлений;
- вычисление обратной матрицы для плохо обусловленной системы даёт заметно большую ошибку проверки $A^{-1}A-E$ (порядка $10^{-8}$), что согласуется с чувствительностью задачи.
